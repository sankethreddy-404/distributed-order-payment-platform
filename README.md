# Distributed Order & Payment Platform

A distributed backend system built using Go to learn microservices,
payment processing, event-driven architecture, caching,
observability, and distributed systems concepts.

## Planned Features

- Order creation and management
- Payment processing
- Payment idempotency
- Event-driven communication
- Notifications
- PostgreSQL persistence
- Redis caching
- gRPC communication
- Kafka messaging
- Docker containerization
- OpenTelemetry
- SigNoz observability

## Services

### Order Service
Responsible for creating and managing orders.

### Payment Service
Responsible for processing payments and storing payment status.

### Notification Service
Responsible for generating notifications after payment processing.
